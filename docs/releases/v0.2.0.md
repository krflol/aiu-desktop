# AIU desktop 0.2.0

Codex cards now show banked reset balances, credit details, and expiry information.
Manual redemption asks for confirmation and offers the same-request retry when a
provider outcome is uncertain.

A per-account **Auto reset at 1% remaining or less** toggle defaults off. When
enabled, the bundled Go backend can redeem an available reset after a fresh
usage response reports at least 99% used in an eligible five-hour or weekly
window. Checks run while AIU collects usage and honor shared polling limits and
provider cooldowns. The backend waits for fresh usage below the threshold before
another automatic spend, including across restarts and toggle changes.

Resetting refreshes eligible usage windows and moves the weekly reset date.
See [reset policy and recovery](../banked-resets.md) before enabling automation.

The bundled Go revision is recorded in `backend.json` and `BACKEND.txt`. It is
based on upstream v0.2.0, where portability PR #11 has merged, with the additional
reset work from [upstream PR #13](https://github.com/getparable/aiu/pull/13).
Rust remains a frontend: it has no access to credential files or provider APIs.

Existing installer choices, native tray behavior, and platform dependencies remain
documented in [platform support](../platform-support.md). Fixture and automated
tests use synthetic accounts and do not spend real banked credits.
