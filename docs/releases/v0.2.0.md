# AIU desktop 0.2.0

Codex cards now show banked reset balances, credit details, and expiry information.
Manual redemption asks for confirmation and offers the same-request retry when a
provider outcome is uncertain.

A per-account **Auto reset** toggle defaults off. Its configurable threshold
accepts whole percentages from **0 to 99% remaining**, defaulting to **1%**; zero
means fully exhausted. Save the threshold in the panel or with
`aiu auto-reset codex:NAME --threshold 5`, independently of the enabled state.
When enabled, the bundled Go backend can redeem an available reset after a fresh
usage response reaches that remaining quota in an eligible five-hour or weekly
window. Checks run while AIU collects usage and honor shared polling limits and
provider cooldowns. The backend waits for fresh recovery above both the current
and prior-attempt thresholds before another automatic spend, including across
restarts, percentage edits, and toggle changes.

Resetting refreshes eligible usage windows and moves the weekly reset date.
See [reset policy and recovery](https://github.com/krflol/aiu-desktop/blob/v0.2.0/docs/banked-resets.md) before enabling automation.

The bundled Go revision is recorded in `backend.json` and `BACKEND.txt`; this
release uses official upstream [Go v0.3.0](https://github.com/getparable/aiu/releases/tag/v0.3.0).
Portable backend support and banked reset features have merged upstream in
[PR #11](https://github.com/getparable/aiu/pull/11) and
[PR #13](https://github.com/getparable/aiu/pull/13). Rust remains a frontend: it
has no access to credential files or provider APIs.

## Release assets

The release includes four Rust desktop archives:

- `aiu-desktop-0.2.0-windows-amd64.zip`
- `aiu-desktop-0.2.0-linux-amd64.tar.gz`
- `aiu-desktop-0.2.0-macos-amd64.zip`
- `aiu-desktop-0.2.0-macos-arm64.zip`

It also includes six standalone Go CLI archives:

- `aiu-cli-0.2.0-windows-amd64.zip` and `aiu-cli-0.2.0-windows-arm64.zip`
- `aiu-cli-0.2.0-linux-amd64.tar.gz` and `aiu-cli-0.2.0-linux-arm64.tar.gz`
- `aiu-cli-0.2.0-macos-amd64.zip` and `aiu-cli-0.2.0-macos-arm64.zip`

Every archive has a `.sha256` sidecar and includes backend provenance. The
release also provides `install.py` and `backend.json`, covered by
`installer-checksums.txt`. The installer defaults to upstream SwiftUI through
Homebrew on macOS; use `--frontend rust` to select the Rust app there. See
[platform support](https://github.com/krflol/aiu-desktop/blob/v0.2.0/docs/platform-support.md) for runtime dependencies, archive
names, and installation details. Archive names use the distribution version
`0.2.0`; `aiu --version` reports the bundled Go backend version, `0.3.0`.

Fixture and automated tests use synthetic accounts and do not spend real banked
credits.
